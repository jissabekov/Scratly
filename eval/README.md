# Eval artifacts

Generated by `scripts/eval_conversation_suite.py`. Not required for running the app.

| Path | Purpose |
|---|---|
| `traces/latest/` | Current 21-scenario proof run (per-scenario JSON + `suite_report.json` + `reassessment.json`) |
| `analyze_post_fix.py` | Summarize a trace directory + assertion violations |
| `suite_run_latest.log` | Tee output from the most recent full suite run |

## Regenerate

```bash
# API + Postgres must be running; see docs/local-development.md
.venv/Scripts/python scripts/eval_conversation_suite.py --out-dir eval/traces/latest
.venv/Scripts/python eval/analyze_post_fix.py latest
```

Trace JSON files are large (~24MB full suite). See [docs/eval-suite.md](../docs/eval-suite.md).
