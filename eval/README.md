# Eval artifacts

Generated by `scripts/eval_conversation_suite.py`. Not required for running the app.

| Path | Purpose |
|---|---|
| `traces/<run>/` | Per-scenario JSON dumps + `suite_report.json` |
| `analyze_post_fix.py` | Summarize a trace directory + assertion violations |
| `suite_run*.log` | Tee output from eval runs (committed for audit) |

## Regenerate

```bash
.venv/Scripts/python scripts/eval_conversation_suite.py --out-dir eval/traces/post-fix
.venv/Scripts/python eval/analyze_post_fix.py post-fix
```

Trace JSON files are large (~24MB full suite); keep locally or in CI artifacts. See [docs/eval-suite.md](../docs/eval-suite.md).
